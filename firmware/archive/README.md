# 이전 스케치 보관

## OnyxSDI_BLE_v1_3

2026-06-01 판. IMU도 배터리 보고도 없던 시절의 코드이고, 지금 펌웨어와
공유하는 것은 두 가지다.

- **FSR 역전** — `1023 - analogRead()`. 안 눌리면 0, 눌리면 1023이 되도록
  뒤집는다. 대시보드의 모든 숫자가 이 방향을 전제한다.
- **7필드 CSV** — `fsr1..fsr4,roll,pitch,yaw\n`. v1.3은 각도 자리에 0을
  넣어 보냈고, 규약 자체는 그때 정해졌다.

읽기는 채널당 `analogRead` 한 번이었다. v2.9에서 5회 중앙값으로 바뀐 것이
바로 이 부분이다.

## 원본 스케치(`onyx_foot.ino`)에 대하여

`firmware/verify_source.py`는 원래 데스크톱의 `onyx_foot/onyx_foot.ino`를
"손대지 않은 원본"으로 삼아 현재 펌웨어와 비교했다. 그 방식은 버렸다.

2026-09-12에 그 파일이 v2.9 내용으로 덮여 있는 것을 확인했다. 리포 밖의,
아무나 덮어쓸 수 있는 한 파일에 검증의 근거를 두고 있었기 때문에, 덮이는
순간 비교는 "같다"를 조용히 통과시킨다. 검증으로서 값이 없다.

지금은 지켜야 할 성질을 스크립트 안에 직접 적어두고 현재 펌웨어만 검사한다.
비교 대상이 없으므로 덮어쓰기로 무력화되지 않는다.
