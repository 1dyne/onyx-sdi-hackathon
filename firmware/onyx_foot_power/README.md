# Onyx NU40-DK 배터리·충전 상태 펌웨어

대상: NUCODE NU40-DK, 1셀 3.7V 150mAh LiPo, BAT 커넥터 연결, USB-C 충전.
이 폴더의 INO와 H 파일 3개를 함께 보관하세요.

이 펌웨어는 원래 데스크톱의 `onyx_foot/onyx_foot.ino`를 입력으로 만들었고,
`verify_source.py`가 그 파일과 줄 단위로 비교해 센서 처리가 안 바뀌었음을
보장했습니다. 그 방식은 버렸습니다. 2026-09-12에 그 파일이 v2.9 내용으로
덮여 있는 것을 확인했고, 비교 대상이 덮이면 비교는 조용히 통과하기
때문입니다. 지금은 지켜야 할 성질을 스크립트 안에 직접 적어두고 이 폴더의
소스만 검사합니다. 근거가 되는 이전 판은 `../archive/`에 있습니다.

## 업로드 전에 필요한 변경

**기존 배선에 그대로 업로드하는 버전이 아닙니다.** 공식 NU40-DK Basic 회로도 기준으로 다음 구성이 필요합니다.

| 항목 | 기존 최종 코드 | 새 펌웨어에 필요한 구성 |
|---|---|---|
| CH1 빨강 | A4 / P0.28 | 동일 |
| CH2 노랑 | A2 / P0.04 | 동일 |
| CH3 초록 | A1 / P0.03 | 동일 |
| CH4 파랑 | A0 / P0.02 | **센서 신호선을 A3 / P0.05로 이동** |
| 배터리 전압 | 미측정 | **A0 / P0.02를 보드 배터리 측정 전용으로 사용** |
| IMU | I2C 0x6A | **IMU의 SDO/SA0 주소 선택을 HIGH로 설정해 0x6B 사용** |
| 충전 칩 | 미사용 | BQ25186, I2C 0x6A, SDA=P0.26 / SCL=P0.27 |

배선 작업 시 USB와 배터리를 모두 분리합니다. IMU 모듈의 주소 변경 점퍼/패드 방식은 해당 모듈에 맞게 적용해야 합니다. SDO/SA0가 GND에 고정 연결된 상태에서 전원에 바로 연결하지 마세요. 주소를 소스에서 바꾸는 것만으로 하드웨어 주소는 바뀌지 않습니다.

보드의 배터리 분압 경로는 VBAT → R13 470kΩ → VBAT_MON → R14 1MΩ → GND이고, SB14를 통해 P0.02에 연결됩니다. SB14를 이전 작업에서 끊었다면 배터리 측정이 되지 않습니다. 이 릴리스는 제조사 회로의 연결 상태를 전제로 하며, 개조된 보드에서는 먼저 실제 연결을 확인해야 합니다.

설치된 보드 패키지는 `PIN_VBAT=A7`로 정의하지만, 제조사 회로도와 배터리 예제는 **P0.02/A0**를 사용합니다. 이 펌웨어는 회로도를 따릅니다.

## 추가된 동작

- 기존 Nordic UART의 7필드 CSV와 10Hz 센서 주기를 유지합니다.
- **FSR을 채널당 5회 읽어 중앙값을 보냅니다(v2.9).** 전송 규약과 주기는 그대로이고, 한 줄에 실리는 값이 안정될 뿐입니다. 평균이 아니라 중앙값인 이유는 튀는 한 점 때문입니다. 평균은 끌려가고 중앙값은 버립니다. 순수 ADC 잡음만 놓고 보면 3초 구간의 P90–P10 폭이 대략 절반으로 줄어듭니다. 발이 실제로 움직여서 생긴 폭은 줄지 않습니다.
- **FSR ADC 획득 시간을 3µs에서 10µs로 올렸습니다(v2.9).** nRF52840에서 3µs가 감당하는 소스 임피던스는 10kΩ까지입니다. FSR 분압은 10kΩ 풀업이라 약하게 눌린 구간에서 그 한계에 붙습니다. 한 주기에 20회를 읽어도 200µs입니다.
- 배터리 ADC 측정 때만 12비트/40µs를 사용하고, 압력 센서 측정용 10비트/10µs로 복원합니다. `verify_source.py`가 setup()과 복원값이 어긋나지 않는지 확인합니다.
- 충전 상태: 알 수 없음 / 충전 안 함 / 충전 중 / 충전 완료 / 오류.
- 충전 칩의 전류·전압·보호 설정에는 값을 쓰지 않습니다. I2C 쓰기는 읽을 레지스터 주소 선택에만 사용합니다.
- IMU가 0x6B에서 확인되지 않으면 충전 칩 접근을 생략하고 충전 상태를 알 수 없음으로 보고합니다. IMU 각도는 원본의 실패 동작처럼 0으로 남습니다. 시리얼에 `MISSING_0x6B`, 상태 플래그에 IMU 오류가 표시됩니다.
- `STAT1` 일부 이벤트 비트는 데이터시트상 read-to-clear입니다. 상태 조회가 이벤트 플래그를 소거할 수 있으며, 충전 설정은 변경하지 않습니다.

## 업로드

1. 위의 CH4 입력과 IMU 주소 변경을 적용합니다.
2. Arduino IDE에서 `onyx_foot_power.ino`를 엽니다.
3. 보드: **NUBoards nRF52 → NU40DK nRF52840**. 검증에 사용한 패키지는 `nucode:nrf52` **1.0.2**입니다.
4. 라이브러리: 기존과 동일한 Adafruit TinyUSB, Bluefruit(보드 패키지 포함), Adafruit LSM6DS, Adafruit BusIO, Adafruit Unified Sensor, Madgwick.
5. `FOOT_NAME`을 왼발 `Onyx-L`, 오른발 `Onyx-R`로 바꿔 각각 업로드합니다.
6. 시리얼 모니터 115200bps에서 `IMU=OK`와 `[POWER]` 로그를 확인합니다.

컴파일만 실행했으며 기기에는 업로드하지 않았습니다. 소스를 업로드할 때에는 H 파일도 같은 폴더에 있어야 합니다.

## 실기 확인

- **v2.9를 올린 뒤에는 양발 모두 baseline을 다시 잡고, 등록된 drill의 기준값도 다시 잡습니다.** 중앙값 필터와 획득 시간 변경은 같은 하중에서 읽히는 숫자를 조금 바꿉니다.
- CH1~CH4를 하나씩 눌러 채널이 맞는지 확인하고 baseline을 다시 잡습니다.
- 무압 상태에서 배터리 전압이 발바닥 압력에 따라 변하지 않는지 확인합니다. 변한다면 A0와 센서가 아직 공유되거나 전원/배선 문제가 있습니다.
- 배터리 연결 상태를 유지한 채 USB를 넣고 빼서 충전 칩의 입력 전원과 충전 상태가 바뀌는지 확인합니다.
- 측정 전압을 멀티미터와 비교합니다. 필요할 때만 `ONYX_VBAT_CALIBRATION`을 실측 전압 / 표시 전압으로 보정합니다.
- USB가 연결돼도 배터리가 충전 완료·비활성·오류 상태일 수 있습니다. USB 연결만으로 충전 중이라고 판정하지 않습니다.
- 이 회로에서는 배터리를 뽑아도 BAT 단자에 전압이 나타날 수 있습니다. **배터리 유무 자동 판별은 제공하지 않습니다. 배터리를 연결한 상태에서 사용합니다.**
- 퍼센트 필드는 3.0~4.2V를 0~100으로 환산한 **전압 수준 참고값**입니다. 402025 셀의 실제 용량이나 남은 사용 시간을 측정한 값이 아닙니다. UI에서는 `전압 수준(참고)`로 표시하고 정확한 잔량으로 표현하지 마세요. 충전 중·부하 변화 시 참고값이 달라집니다.

## 대시보드 연동 규약

현재 대시보드에는 이 서비스의 수신/표시 코드가 없습니다. **이 펌웨어를 업로드하는 것만으로 대시보드에 배터리가 표시되지는 않습니다.**

서비스 UUID: `9c7e0001-7e71-4b8d-a491-3f886d9f51a0`
특성 UUID: `9c7e0002-7e71-4b8d-a491-3f886d9f51a0` (read + notify)

브라우저 `requestDevice`의 `optionalServices`에 서비스를 추가하고 기기를 다시 선택해야 합니다. Nordic UART는 기존대로 별도로 구독합니다. 광고 패킷에는 기존 NUS UUID를 유지하므로 이 서비스는 연결 후 탐색합니다.

| 바이트 | 의미 |
|---|---|
| 0 | 스키마 버전 1 |
| 1 | 플래그: bit0 전압 유효, bit1 충전 레지스터 유효, bit2 전압 수준 유효, bit3 입력 전원 양호, bit4 감지된 충전 오류, bit5 퍼센트가 참고값, bit6 IMU 미확인 |
| 2–3 | 배터리 mV, uint16 little-endian. 65535=알 수 없음 |
| 4 | 전압 수준 0–100, 255=알 수 없음 |
| 5 | 0=알 수 없음, 1=충전 안 함, 2=충전 중, 3=칩의 충전 완료 상태, 4=오류 |
| 6–7 | 12비트 평균 ADC raw, uint16 little-endian |
| 8–11 | 측정 시점 부팅 후 ms, uint32 little-endian, 약 49.7일 후 순환 |
| 12–15 | BQ25186 STAT0, STAT1, ICHG_CTRL, MASK_ID. bit1이 0이면 무효 |

전압과 충전 상태의 유효성 플래그를 각각 확인해야 합니다. 연결이 끊기거나 마지막 수신 후 15초가 지나면 이전 값을 현재 상태처럼 표시하지 마세요.

- LSM6DS3TR-C: https://www.st.com/resource/en/datasheet/lsm6ds3tr-c.pdf — SDO/SA0에 따른 0x6A/0x6B 주소 선택.
